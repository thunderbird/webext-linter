Unreadable Experiment schema error

experiment-schema-invalid

What it detects

An Experiment schema file, declared by experiment_apis in manifest.json and packaged in the add-on, that Thunderbird cannot read. Thunderbird reads every declared schema when it installs the add-on and refuses the add-on if one is not UTF-8 or UTF-16 text, or not JSON as its loader reads it (only // comments are allowed).

A declared schema that is not packaged at all is reported by bundled-files instead. A schema file named by more than one Experiment is reported once.
