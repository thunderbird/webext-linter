Theme experiment missing strict_max_version error

theme-experiment-missing-strict-max-version

What it detects

A theme experiment (an add-on that declares theme_experiment) that does not pin a strict_max_version. Its stylesheet styles Thunderbird's internal user interface, which changes between major versions, so without a maximum supported version the theme can break silently when the user upgrades.

A theme experiment runs no privileged code, so it is not an Experiment and none of the Experiment checks apply to it. An add-on that is both an Experiment and a theme experiment is left to experiment-missing-strict-max-version, so the developer is told once. The check is silent for theme experiments that already declare a maximum.

When it fires The developer is told the add-on ships a theme_experiment whose stylesheet styles Thunderbird's internal user interface, and that because this interface changes between major Thunderbird versions a theme experiment must set the gecko strict_max_version in browser_specific_settings.

Source of truth: src/checks/rules/theme-experiment-missing-strict-max-version.js and its entry in assets/registry.yaml.
