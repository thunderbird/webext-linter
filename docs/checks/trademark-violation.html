Trademark violation error

trademark-violation

What it detects

Mozilla's trademark policy forbids certain brand names in an add-on's name outright. "Firefox", "Mozilla" and "MZLA" are never allowed, in any form and in any language.

The check reads the add-on name from the manifest. If the name is a localized __MSG_…__ placeholder, it resolves the real text from every locale file and checks each one, reporting every offending name rather than only the first. All matching is case-insensitive, and needs no knowledge of the language, which is why this half is decided here.

"Thunderbird" is not checked here. It is allowed in one construction, "<name> for Thunderbird", and recognising that outside English needs the meaning of the word before it, so it is split across two sibling checks by who can answer it: Thunderbird in a localized add-on name for names that arrive with a locale tag, and Thunderbird in an unlocalized add-on name for a name whose language nothing in the package states. The add-on icon is the third trademark vector, but being an image it is left to manual review.

When it fires The add-on is told its name uses a registered Mozilla trademark, and that "Mozilla", "Firefox" and "MZLA" are not allowed in an add-on name at all.

Source of truth: src/checks/rules/trademark-violation.js and its entry in assets/registry.yaml.
