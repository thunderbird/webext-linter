Source does not build into the submitted XPI error

build-not-reproduced

What it reports

A source-code submission whose build completes, but whose result does not match the submitted XPI.

Nothing in the files decides it, so the check raises nothing itself. A plain review asks build-reproduces-xpi instead, whose one response covers every reason. Under --llm-review that question is put to the reviewer alone in the built phase, with four answers, and answering Does not reproduce reports this check in its place.

When it fires The add-on is told that the submitted source builds, but the result does not match the submitted XPI, and that the XPI must be built from exactly the submitted source by the build instructions it provided.
It aborts the review It settles the submission on its own: nothing further is put to a reviewer, and the developer’s text ends on the reason it is incomplete (“Build process issues”). The build question is cleared, so this is the one build finding.

Source of truth: src/checks/rules/build-not-reproduced.js, the built phase and the entry in assets/registry.yaml.
