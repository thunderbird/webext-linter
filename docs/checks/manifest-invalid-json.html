Invalid manifest.json error

manifest-invalid-json

What it detects

A manifest.json is present at the add-on root but does not give a JSON object, so the submission cannot be read. Two ways to fail: the text will not parse, or it parses to a primitive or an array.

Where the text will not parse this is the single finding — every other manifest check needs a parsed manifest. A truthy non-object is still read as a manifest downstream, so their findings arrive beside this one.

Decision flow

flowchart TD
  A["manifest.json at the add-on root"] --> B{"Did it parse as JSON?"}
  B -- no --> ERR([ERROR: invalid manifest JSON])
  B -- yes --> C{"Is what it holds
a JSON object?"}
  C -- no --> ERR
  C -- yes --> OK([no finding — handled by
the other manifest checks])

When it fires The add-on is told manifest.json is not a valid JSON object, with a link to the WebExtension API documentation.
