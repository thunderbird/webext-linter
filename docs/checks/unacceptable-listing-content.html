unacceptable-listing-content

What it detects

This is a human-review item with no automated logic behind it. A reviewer reads the add-on listing page on ATN: its summary, description and screenshots.

Each is weighed for spam, inappropriate or misleading content, and against Mozilla's Acceptable Use Policy. Nothing judged here is in the package, so every fix is an edit on addons.thunderbird.net and no new version is needed. What the add-on itself ships is judged separately by unacceptable-package-content.
